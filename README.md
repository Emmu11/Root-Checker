# Root Checker

> A fast, clean and modern web-based tool for checking Android root-related information.

[![Live Preview](https://img.shields.io/badge/Live%20Preview-View%20Project-111827?style=for-the-badge)](https://rootchecker-by-emmu.netlify.app/)

## About

Root Checker is a lightweight web tool built to make Android device checks simple and easy to understand. It provides a clean interface for checking available root-related information directly from the browser, along with useful device details.

The project focuses on a straightforward experience: open the tool, run the check, and get clear results without unnecessary steps.

## Features

* Root-related browser checks
* Device and browser information
* Responsive and mobile-friendly interface
* Clear and easy-to-read results
* Lightweight frontend
* No account required

## Browser Limitations

Web applications do not have direct access to all Android system-level information. Because of this, a browser-based tool cannot provide the same level of root verification as a native Android application.

The results provided by this project should therefore be treated as browser-based checks rather than definitive proof of system root access.

## Privacy

The project is designed with privacy in mind. No account, password, or unnecessary personal information is required to use the tool.
